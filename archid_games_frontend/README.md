# Archid Games Frontend (AngularJS)

Migrated from React to **AngularJS (1.x)**.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
   View the web app at [http://localhost:3000](http://localhost:3000).

## Project Structure

- `src/index.html` – Main HTML file and AngularJS app bootstrap
- `src/app/` – All JS/AngularJS modules, controllers, services, templates
- `src/styles/` – App-wide and component CSS

## Features

- **User authentication** (sign in/up/out)
- **Browse Games**
- **Play games & submit scores**
- **Leaderboard**
- **Profile management**

## Theme

Light/modern, accent: `#fbbf24`, primary: `#1e90ff`, secondary: `#23272f`.

## Scripts

- `npm start` – Start development server
- `npm run build` – Build for production
